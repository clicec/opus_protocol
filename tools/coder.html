MSREP response coder

Codes model responses against the §5.3 table. Everything stays in your browser — nothing is uploaded, and there is no server.

You do not need to have read the protocol, and it is better if you haven't. This is a test of whether a written codebook produces the same labels in two independent hands. Someone who already knows the design intent will reconstruct it from context and hide the ambiguity the test is looking for.

“I couldn’t tell which code applied” is a result, not a failure. There is a button for it on every response. Use it whenever it is true. A run where you press it fifteen times is more useful than one where you guessed fifteen times.

Responses are shown in random order with item identifiers hidden, so that you judge each one on its own rather than against its neighbours.
